# **App Name**: CyberGuard AI

## Core Features:

- Phishing Detection Chatbot: Integrate with Google Gemini AI and a Gradient Boosting Classifier to detect phishing URLs in real-time.
- Automated Threat Analysis: Automatically analyze threats using feature extraction and verify email breaches via the XposedOrNot API.
- Real-time Detection Interface: Provide a Streamlit-based UI that ensures phishing detection happens rapidly (under 1 second response time).
- Phishing Detection tool: Implement a tool that incorporates a reasoning engine to automatically scan URLs or email content to determine if phishing attempts are made. If a url has been scanned and labeled once it will be saved.
- Security Auditing Tools Integration: Integrate with Wireshark, Nessus, and Burp Suite for comprehensive penetration testing.

## Style Guidelines:

- Primary color: Dark slate blue (#3F51B5) to convey trust and security.
- Background color: Very light grey (#F5F5F5) to offer a professional and clean look.
- Accent color: Teal (#009688) to highlight key interactive elements and alerts.
- Body and headline font: 'Inter', sans-serif, for a modern, clean, and easily readable interface.
- Use flat, consistent icons for representing different types of threats and tools.
- Maintain a clean, grid-based layout for easy navigation and data visualization. Emphasize negative space to avoid clutter.
- Use subtle transitions and animations to provide feedback and enhance user experience. For instance, loading indicators during threat analysis.
